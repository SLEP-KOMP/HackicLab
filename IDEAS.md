# Идеи и планы HackicLab

Список потенциальных фич и улучшений. Это НЕ обязательные пункты — только идеи
для обдумывания. Реализация каждой требует отдельного описания (UX, зависимости,
тесты, i18n). Версия приложения и релизы этим файлом не затрагиваются.

## Сетевая загрузка: OpenNetworkBoot (обдумывается)

**Статус:** идея, без реализации.

**Что это:** UEFI-драйвер-плагин OpenCore (`OpenNetworkBoot.efi`), реализует
`OC_BOOT_ENTRY_PROTOCOL` и добавляет в меню OpenCore сетевые варианты загрузки —
PXE и HTTP(S) Boot. По доке OpenCore 1.0.9 (секция 11.8) умеет, в частности,
грузить `.dmg` + `.chunklist` по HTTP(S), т.е. запускать macOS Recovery из сети.

**Зачем может понадобиться:** пользователям с PXE/HTTP-сервером в локальной сети
(NAS, kextcache, кластер, тесты) — загрузка/установка macOS без флешки.
Для типичного пользователя сети не нужно (обычно хватает флешки).

**Что понадобится для реализации (если когда-то решим):**
- добавить `OpenNetworkBoot.efi` в `UEFI/Drivers` (`builder.py`, рядом с
  `OpenRuntime.efi`/`OpenHfsPlus.efi`) и в конфиг (`config_gen.py`);
- учесть сетевые драйверы-зависимости (`HttpBootDxe.efi`, `Ip4Dxe`, `Ip6Dxe`,
  `DnsDxe`) в `efi_layout.py`;
- UI-опция «Сетевая загрузка» в шаге «Опции» мастера (тогл http/https + поле URI),
  по умолчанию выключена;
- i18n (RU/EN) и тесты.

**Рекомендация:** не приоритет. Появляется только как опциональная галочка,
а не обязательный компонент сборки.

## Другие идеи из обзора сообщество / документации

- UEFI-драйверы из доки OpenCore 1.0.9, которых нет в HackicLab: **AudioDxe**
  (звук в загрузчике), **OpenLegacyBoot**.
- Сторонние инструменты из закреплённой шапки сообщество: **PowerDownHackintosh**
  (выключение кнопкой корпуса в одно касание), **Mist** (загрузка образов
  macOS) — изучить как источник идей.
