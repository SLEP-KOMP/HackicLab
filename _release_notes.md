# HackicLab 0.0.0 — отдельная вкладка портов, яблоко в прогрессе и QR-код

Первый релиз с чистого листа. Файлы называются так, чтобы сразу было видно,
что это и для какой платформы:

- `HackicLab_0.0.0_windows_x64.exe` — Windows x64;
- `HackicLab_0.0.0_macos_apple_silicon.zip` — Mac с Apple Silicon (arm64);
- `HackicLab_0.0.0_macos_intel.zip` — Mac с Intel (x86_64).

К каждому файлу лежит `.sha256`.

## Порты и диски — новая вкладка

- **Карта USB-портов переехала из «Записи на USB» в отдельную вкладку «Порты и диски»**
  и работает по обеим сборкам: порты читаются из DSDT прошивки (через `iasl`),
  при недоступности — через `usbdump.exe` из USBToolBox.
- **Порты выбирает пользователь.** Показываются все порты контроллера с типом
  коннектора (USB 2.0 / USB 3.0 / внутренний), у каждого свой флажок. Сверх
  лимита macOS (15 портов на контроллер) флажки снимаются автоматически, а если
  включить их больше — сохранение блокируется с подсказкой.
- **Почему лимит.** AppleUSBXHCI держит таблицу из 15 портов на контроллер:
  дальше macOS выбирает порты произвольно, часть не работает. USB 3.0-порт
  занимает две записи — USB 2.0 и USB 3.0. Квирк `XhciPortLimit` обходит лимит
  только на старых macOS и может повреждать данные, поэтому карта собирается
  без него.
- **Карта дисков** (диски, разделы, ESP, Windows / OpenCore / Linux / rEFInd,
  предупреждения о дубликатах OpenCore и MBR) переехала сюда же — из записи на
  флешку она была не к месту.

## Запись на USB

- На вкладке остались только шаги записи: флешка, режим, источник EFI,
  установщик macOS Recovery, история сборок, резервные копии и журнал.
- **Права администратора** запрашиваются один раз при старте EXE: отдельного
  UAC-подтверждения и перезапуска перед записью больше нет.

## Интерфейс

- **Страница «Ручная сборка» стала компактнее**: отдельная карточка с яблоком
  убрана, прогресс сборки, записи на USB и мастера рисуется яблочным
  прогресс-баром прямо на месте обычной шкалы.
- **«Поддержка»**: вместо фото автора — QR-код на страницу перевода
  (ЮMoney / СБП / карта банка). Сканируется камерой телефона, сумму можно
  поменять на странице оплаты.

## Исправления

- Убраны остатки перезапуска с UAC (`relaunch_as_admin`, отложенный профиль).
- Устаревший комментарий про MBR-разметку флешек исправлен: карта строится как
  GPT, для SSD — GPT+ESP.
- Сборка переносит версию в имя EXE; macOS-архивы в CI тоже получают версию и
  платформу в имени.

## Установка

Портативный EXE — запустите, установка не требуется. Делайте резервные копии
важных данных: запись EFI стирает содержимое флешки.
