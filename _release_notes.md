## HackicLab v1.0.1 — безопасная запись на USB и проверяемые загрузки

Патч-релиз: закрывает риски при записи на флешку и при скачивании компонентов из сети.

### Исправления

- **Защита от стирания не той флешки.** Перед `clean` HackicLab заново читает параметры диска: `BusType` обязан быть `USB`, системный и загрузочный диск запрещены, номер диска сверяется с выбранной буквой. Раньше проверка была только при построении списка, и смещение номеров после переподключения накопителя могло привести к записи на чужой диск.
- **Реальный GPT + ESP.** Форматирование теперь создаёт таблицу GPT и EFI-раздел (`convert gpt`, `create partition efi`), как и было заявлено в описании режима «Полная запись».
- **Проверяемый TLS.** Убран fallback, отключавший проверку сертификата: OpenCore, kext и `macrecovery.py` больше не скачиваются по непроверенному соединению. Скачанный `macrecovery.py` дополнительно валидируется перед запуском (компиляция + ожидаемые ключи CLI).
- **Кэш macrecovery.** В EXE-сборке скрипт больше не скачивается заново при каждом запуске — он сохраняется в `~/.hackiclab/cache`.
- **Стабильный идентификатор устройства.** `device_id` в лицензии считается детерминированно; раньше из-за `hash()` он менялся между запусками.
- **Права администратора по требованию.** EXE больше не требует UAC на старте: повышение запрашивается только в момент записи EFI на флешку, с предложением перезапуска.
- **Кэш AMD_Vanilla** обновляется раз в 7 дней, при отсутствии сети используется сохранённая копия.

### Инфраструктура

- 34 автотеста на `unittest` (проверка цели записи, скрипты diskpart, `config.plist`, переводы RU/EN, `device_id`, кэш патчей): `python -m unittest discover -s tests -t tests`.
- `requirements.txt` и `requirements-dev.txt` вместо установки пакетов «на глаз».
- Release notes теперь хранятся в репозитории.

### Установка

Портативный `HackicLab.exe` — скачайте из вложений и запустите. Установка не требуется; права администратора нужны только на запись флешки.

> ⚠️ Проект создан для изучения и законного использования. Устанавливайте macOS только на оборудование, которое вы имеете право использовать, соблюдая лицензию Apple.
