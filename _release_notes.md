## HackicLab v1.0.1 — безопасная запись на USB, каталог конфигураций и автообновление

Сборка 1.0.1 обновлена: к исправлениям безопасности добавлены каталог типовых
конфигураций, новые темы и проверка обновлений через GitHub.

### Безопасность и исправления

- **Защита от стирания не той флешки.** Перед `clean` HackicLab заново читает параметры диска: `BusType` обязан быть `USB`, системный и загрузочный диск запрещены, номер диска сверяется с выбранной буквой. Раньше проверка была только при построении списка, и смещение номеров после переподключения накопителя могло привести к записи на чужой диск.
- **Реальный GPT + ESP.** Форматирование создаёт таблицу GPT и EFI-раздел (`convert gpt`, `create partition efi`), как и было заявлено в описании режима «Полная запись».
- **Проверяемый TLS.** Убран fallback, отключавший проверку сертификата: OpenCore, kext и `macrecovery.py` больше не скачиваются по непроверенному соединению. Скачанный `macrecovery.py` дополнительно валидируется перед запуском.
- **Кэш macrecovery** в EXE-сборке сохраняется в `~/.hackiclab/cache` и не скачивается заново при каждом запуске.
- **Стабильный идентификатор устройства** в лицензии (раньше `hash()` менялся между запусками).
- **Права администратора по требованию.** EXE больше не требует UAC на старте: повышение запрашивается только при записи EFI на флешку.
- **Кэш AMD_Vanilla** обновляется раз в 7 дней, при отсутствии сети используется сохранённая копия.
- Исправлены неопределённые имена (`ssl`, `sys`), мёртвый код и десятки неиспользуемых импортов — линтер проходит чисто.

### Новое

- **Каталог конфигураций** на вкладке «Источники»: **23 типовые связки** — настольные Intel (Sandy Bridge, Ivy Bridge, Haswell, Skylake, Kaby Lake, Coffee Lake, Comet Lake, Raptor Lake) и AMD (Zen, Zen+, Zen 2, Zen 3), ноутбуки (ThinkPad T440p, T480, X230, XPS 9360, IdeaPad 3), мини-ПК (NUC7, NUC8, NUC10), рабочие станции (Xeon E5 на X99, Core i9 на X299, Threadripper). Для каждой — диапазон macOS, статус поддержки, нужные kext/SSDT/quirks и ссылки на первоисточники. Работают поиск и фильтр по категориям.
- **Вердикт «сборка поддерживается»** для каждой записи: HackicLab проверяет, есть ли платформа OpenCore, модель SMBIOS, все kext и SSDT, укладывается ли macOS в потолок платформы и генерируется ли `config.plist`. Сгенерированные конфиги для всех 22 рабочих связок проходят `ocvalidate` 1.0.8 без ошибок; IdeaPad 3 на мобильном AMD честно помечен как неподдерживаемый.
- **Живая база железа**: при сканировании HackicLab запоминает обезличенный отпечаток (CPU, поколение, платформа, GPU, плата) в `~/.hackiclab/hardware_registry.json`. Если конфигурации нет в каталоге, во вкладке «Источники» появляется предложение отправить её в базу — открывается GitHub Issue с уже заполненными полями, без серийников и MAC.
- Потолки macOS по поколениям пересмотрены по официальному списку поддерживаемых Mac: Coffee Lake и Comet Lake — Sequoia, Kaby Lake — Ventura, Skylake/Broadwell/Haswell — Monterey, Ivy Bridge — Catalina, Sandy Bridge — High Sierra; Skylake-X (iMac Pro 2017) — Sequoia.
- **Темы оформления.** По умолчанию — системная тема Windows (следит за сменой на лету). Переключатели сделаны в виде экранов монитора: Системная, Светлая, Тёмная, Моя тема. Добавлены встроенные темы в духе macOS — Aqua, Графит, Sonoma, Big Sur — и свой фон для «Моей темы». Системная тема учитывает режим высокой контрастности Windows: тёмная схема больше не превращается в светлую, а подписи плиток читаются на любом фоне. Страница настроек прокручивается.
- **Проверка обновлений через GitHub.** Кнопка «Проверить обновление», список изменений, «Обновить сейчас» / «Отложить» с напоминанием. EXE обновляется на месте: сборка скачивается в `%LOCALAPPDATA%\HackicLab\update`, текущий файл переименовывается в `.old`, на его место копируется новая версия и приложение перезапускается само. Вспомогательных cmd-окон и ожидания PID больше нет. При запуске HackicLab сам проверяет релиз и предлагает обновиться. Если релиз перезалили без смены номера версии, обновление всё равно определяется: приложение сравнивает sha256 своего EXE с digest вложения в релизе и показывает «доступна пересборка версии».

- **Стабильность.** Устранён дубль обработчика ошибки списка USB-устройств (при сбое перечисления показывался неверный диалог), добавлены проверки `None` при очистке панелей и работе с путями, Qt-константы переведены на scoped-формы. Статическая проверка (Pylance/pyright, базовый режим) по всему проекту — 0 замечаний, Ruff — чисто.

- **Интерфейс.** Единая современная тема оформления: карточки, скругления, тонкие границы, аккуратные поля и списки, кастомные скроллбары, статусные цвета (успех/предупреждение/ошибка) вместо жёстко заданных. У каждой страницы — заголовок и короткое пояснение, у пустых состояний — понятная подсказка, в журналах — плейсхолдеры.
- **Встроенные темы стали различимыми.** Aqua, Графит, Sonoma и Big Sur теперь меняют не только акцент, но и фон окна (у каждой свой градиент), панель, карточки, поля, кнопки и скроллбары.
- **Язык интерфейса по системе.** Если пользователь ещё не выбирал язык, HackicLab берёт его из Windows: русский для ru-локали, иначе английский. Выбор сохраняется в `~/.hackiclab/ui.json` и больше не сбрасывается при перезапуске.

- **Валидация без пустых панелей.** Четыре списка ocvalidate собраны во вкладки («Пропущенные ключи / Ошибки схемы / Предупреждения / Аудит»), в заголовках вкладок — число замечаний, статус проверки больше не кричит заголовком, дубль подзаголовка убран.
- **Анализ EFI.** Результаты в отдельной карточке: подсказка до запуска, пояснение в панели деталей, журнал OpenCore с плейсхолдером. Цвета серьёзности берутся из текущей темы, поэтому список перекрашивается вместе с оформлением.
- **Порты, диски и сборка.** У «Карты дисков» и журналов появились подсказки и разумные высоты вместо пустых простыней, продублированный заголовок «Целевая версия macOS» убран.

- **Новая вкладка «Поддержка».** Добровольная поддержка проекта через кошелёк ЮMoney `4100115796556073`: калькулятор комиссии (0% от 4 000 ₽ на сайте и в приложении, 1% ниже), проверка лимита 15 000 ₽ за перевод, кнопки «Открыть страницу перевода» и «Скопировать номер кошелька», официальные логотипы ЮMoney, МИР и СБП без изменений, блок «На что идут средства» и фото автора.
- **Исправлена смена языка.** При переключении языка навигация падала с `IndexError`, потому что список иконок был захардкожен; теперь иконки берутся из конфигурации меню.

### Исправления после первого выпуска вкладки «Поддержка»
- **Фото и логотипы в сборке.** В onefile-EXE `__file__` модуля бывает относительным, поэтому картинки не находились: путь к ассетам теперь берётся из `sys._MEIPASS`. Логотипы ЮMoney, МИР и СБП собраны в одну горизонтальную полосу.
- **Язык на старте.** Определение языка шло до создания `QApplication`, где `QLocale` отдаёт `en-US`, — русская Windows получала английский интерфейс. Теперь основным источником служит `GetUserDefaultUILanguage` (ru → русский, иначе английский), а настройки старой версии один раз мигрируют на «Системная тема + язык системы».
- **Тема на старте.** Тема по умолчанию — «Системная»; при высокой контрастности Windows определяется тёмная схема.
- **Один экземпляр и чистое обновление.** Второй процесс блокировал файл EXE и мешал PyInstaller удалять `_MEI`: добавлена проверка через `QLocalServer`, убран принудительный `os._exit` после обновления.
- **Устойчивость к урезанному окружению.** `Path.home()` падал с `RuntimeError: Could not determine home directory` — домашний каталог теперь определяется через переменные окружения с запасным вариантом во временной папке.

### Проверка кода (Pylance/basedpyright в стандартном режиме)
- `PowerShell.clear_cache()` вызывал несуществующий `run.cached.cache_clear()` — кэш теперь обычный словарь экземпляра, а `@lru_cache` на методе (он держал ссылку на объект) убран.
- `EFIBuilder`: локальные `import shutil/zipfile` внутри `try` делали имя локальным — при неудачной загрузке OpenCore фильтрация kext падала с `UnboundLocalError`. Импорты подняты на уровень модуля, проверка `'extract' in dir()` заменена обычным `extract is not None`.
- `_resolve_config()` вызывал `.is_file()` у значения из состояния — если приходила строка, проверка падала; путь теперь приводится к `Path`.
- `BuildOptions` может быть `None` в плане сборки — подставляются значения по умолчанию вместо падения на `__dict__`.

### Вкладка «Поддержка»: раскладка как в «Параметрах» Windows
- Контент выровнен центральной колонкой с одинаковыми умеренными отступами слева и справа: на широком окне поля не растягиваются, на узком — колонка занимает доступную ширину.
- Убран искусственный разрыв между блоками и дисклеймером: страница больше не прижимает нижнюю карточку к краю окна.

### Локализация интерфейса
- Кнопки диалогов больше не берутся из стандартных Yes/No: подтверждения используют явные подписи на языке интерфейса («Обновить сейчас / Отложить», «Да / Нет»). Это касается предложения об обновлении, повышения прав и очистки истории.
- В сборку включён `qtbase_ru.qm`, он подключается при старте и при смене языка — стандартные кнопки Qt («Отмена», «Да») теперь на русском.
- Фильтры файловых диалогов («Все файлы», «Изображения», «Лог OpenCore» и т. д.) переведены через `tr.t()`, английских подписей в русском интерфейсе не осталось.
- Сводка сборки и статус `ocvalidate` больше не пишут по-русски в английском интерфейсе — «Итог», «Kexts (скачано N)», «config.plist валиден» теперь ключи `build.log_*`.
- Добавлена сквозная самопроверка: `HackicLab.exe --check-i18n=<файл>` печатает подписи навигации, заголовков, диалогов и фильтров для RU и EN. На сборке подтверждено: RU — «Да / Нет», «Обновить сейчас / Отложить», «Все файлы»; EN — «Yes / No», «Update now / Later», «All files».
- Автотесты: запрет литералов вместо `tr.t()` в UI, запрет русского текста в английских переводах и наоборот, проверка подписей диалогов на обоих языках (тестов теперь 130).

### Инфраструктура

- 130 автотестов на `unittest` (каталог и поддержка сборки, реестр железа, темы, состояние интерфейса, обновления, запись на USB, `config.plist`, переводы): `python -m unittest discover -s tests -t tests`.
- `requirements.txt` и `requirements-dev.txt`, настройки Ruff и Pylance, конфигурация VS Code (`.vscode/`) и `.editorconfig`.
- Release notes хранятся в репозитории.

### Установка

Портативный `HackicLab.exe` — скачайте из вложений и запустите. Установка не требуется; права администратора нужны только на запись флешки.

> ⚠️ Проект создан для изучения и законного использования. Устанавливайте macOS только на оборудование, которое вы имеете право использовать, соблюдая лицензию Apple.
