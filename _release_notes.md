# HackicLab 1.2.1 — порядок во вкладках, карта портов при записи, проверка флешки

Файлы релиза:

- `HackicLab_1.2.1_windows_x64.exe` — Windows x64;
- `HackicLab_1.2.1_macos_apple_silicon.zip` — Mac с Apple Silicon (arm64);
- `HackicLab_1.2.1_macos_intel.zip` — Mac с Intel (x86_64).

К каждому файлу лежит `.sha256`.

## Порядок во вкладках

Теперь чётко разделено: сборка отвечает за содержимое EFI, запись — за носитель,
диагностика — только смотрит.

- **Авто и Ручная сборка**: убраны пикер USB-портов и предупреждения о
  накопителе — вместо них строка-подсказка, где это искать. Дублей больше нет.
- **Запись на USB**: здесь выбирается карта портов, видно предупреждения о
  накопителе, есть проверка флешки после записи.
- **«USB и накопители» → «Диагностика USB и дисков»**: отдельный инструмент
  карты портов и карта дисков, без влияния на сборку.
- **Валидация**: у быстрых правок появилось явное пояснение, что они меняют
  выбранный `config.plist`, а не настройки сборки.

## Карта USB-портов

- Галочка «Собрать карту USB-портов (UTBMap) в EFI» появилась на вкладке
  записи и реально передаётся в запись (`make_usb_map` раньше был мёртвым
  параметром — карта при записи не строилась).

## Проверка флешки

- Кнопка «Проверить флешку»: читает `EFI/OC/config.plist` с носителя и сверяет
  файлы с манифестом целостности сборки. Показывает «пройдено / отличается /
  манифеста нет».

## Предупреждения перед записью

- Флешка меньше 8 ГБ при включённом установщике — предупреждение, что
  поместится только EFI.
- Версия установщика не совпадает с целевой macOS сборки — предупреждение.

## Источники

Добавлены 8 источников: AppleDB, EveryMac, официальные списки моделей Apple
для Sequoia и Tahoe, Dortania Post-Install, Getting Started With ACPI,
релизы OCLP и MountEFI.

## Исправления

- Убран дубль `addLayout` вместо `addWidget` на странице записи.
- Режим «Полная запись» больше не обещает скачивание OpenCore и кекстов:
  запись копирует готовый EFI, скачивание делает сборка.

> Сборка без подписи: Defender иногда ругается на EXE. Сверяйте SHA-256
> с файлом `.sha256` из релиза.
